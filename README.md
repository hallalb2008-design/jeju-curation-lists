# 제주 도서 큐레이션 도우미 — 추천목록 자동 갱신

도우미의 '추천목록' 탭에 들어갈 목록을 매주 자동으로 모아 `data/lists.json` 하나로 만듭니다.
사서는 도우미에서 **'최신 추천목록 받기'** 버튼만 누르면 되고, 인증키가 필요 없습니다.

## 무엇이 자동이고 무엇이 수동인가

| 목록 | 방식 |
| --- | --- |
| 국립중앙도서관 사서추천도서 | 자동 (국립중앙도서관 Open API, 최근 12개월) |
| 국립어린이청소년도서관 사서추천도서 | 자동 (홈페이지 목록, 격월, 유아·초등 저·초등 고·청소년, 최근 12개월, 인증키 불필요) |
| 북스타트 선정 그림책, 한국어린이도서연구회 권장도서, 교육청 목록 | `manual/` 폴더에 CSV를 올리면 자동 반영 |
| ISBN 채우기, 제주 도내 소장 도서관 확인 | 자동 (도서관 정보나루, 1회 450건까지, 남은 건 다음 주에 이어서) |

## 처음 한 번 설정 (담당자 1명)

1. 이 폴더를 깃허브 저장소로 올립니다. 공개 저장소여야 도우미가 목록을 받아 갈 수 있습니다. 저장소에는 공개 추천목록과 소장 여부만 들어가고 인증키·개인정보는 들어가지 않습니다.
2. 저장소 **Settings → Secrets and variables → Actions → New repository secret**에서 두 개를 넣습니다.
   - `NL_API_KEY`: 국립중앙도서관 Open API 인증키
   - `DATA4LIB_KEY`: 도서관 정보나루 인증키
3. **Actions → 추천목록 자동 갱신 → Run workflow**로 한 번 돌립니다.
4. 도우미 '추천목록' 탭의 '목록 주소'에 아래 주소를 넣습니다.
   `https://raw.githubusercontent.com/<계정>/<저장소>/main/data/lists.json`

## 수동 목록 올리는 법

`manual/` 폴더에 CSV를 올립니다. 파일 이름 앞머리로 출처를 구분합니다.

- `bookstart_2025 선정.csv` → 북스타트 선정 그림책 / 목록 이름 '2025 선정'
- `childbook_2026 그림책.csv` → 한국어린이도서연구회 권장도서
- 그 밖의 이름 → 기타 목록

첫 줄은 `서명,저자,출판사,ISBN,대상`입니다(`_양식.csv` 참고). ISBN은 비워도 됩니다.

## 주의

- 한국어린이도서연구회 같은 민간단체 목록을 공개 저장소에 올리기 전에 이용 허락을 받으세요.
- 사서추천도서 API 주소·항목명은 국립중앙도서관 '사서추천도서' 활용방법 페이지 기준입니다(ISBN 항목명이 `recome_isbn`으로 표기됨). 첫 실행 기록에서 도서가 0권이면 `FIELDS`를 확인하세요.
- 국립어린이청소년도서관 목록은 홈페이지 화면을 읽어 옵니다. 실행 기록에 '수집 실패'가 나오면(홈페이지 구조 변경이나 해외 접속 차단) 지난번 목록을 그대로 유지합니다.
